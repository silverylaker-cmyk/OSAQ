# 수면무호흡 원인 평가 설문지 (PART A)

수면무호흡증이 의심되는 환자가 **태블릿에서 직접 작성**하는 웹 설문 프로그램입니다.
원본 문진표의 **PART A(환자 작성)** 만 구현했으며, PART B(진찰 기록)와 PART C(원인 카테고리 해석)는
의료진 작성 영역이므로 포함하지 않았습니다.

## 화면 흐름

```
환자번호 입력 → A1 체중·신체 → A2 코골이·무호흡 양상 → A3 코 증상
            → A4 생활 요인 → A5 동반질환·기타 → A6 주간 졸림(Epworth) → 결과 한 화면
```

- **환자번호만 먼저 입력** — 이름·나이·성별은 받지 않습니다.
- 한 화면에 한 섹션씩, 큰 터치 버튼(최소 60px)으로 구성했습니다.
- 상단 진행 바 + 단계 칩으로 남은 분량을 보여 줍니다.
- 조건부 문항: 수면제 '예' → 약물명 / 고혈압 선택 → 혈압약 개수 / 폐경 후 → 악화 여부.
- 필수 문항을 비우고 다음으로 넘어가려 하면 해당 문항이 붉게 표시되고 그 위치로 이동합니다.
- 작성 중 내용은 브라우저에 자동 임시 저장되어, 태블릿이 잠기거나 새로고침돼도 이어서 작성할 수 있습니다.

## 결과 화면

마지막 단계에서 **전체 입력 내용을 한 화면**에 보여 줍니다.

- 상단 요약 카드 4개: BMI(자동 계산·분류), Epworth 합계 /24, 목격된 무호흡, 목 치수(cm 환산)
- 참고 소견 뱃지: 체중 증가, 목둘레 40cm 이상, 자세 의존성, 비강 요인, 취침 전 음주,
  수면제 복용, 흡연, 혈압약 3제 이상, 가족력, 폐경 후 악화, Epworth 10점 이상 등
- A1~A5 전체 응답을 2열 그리드로, A6는 8문항 점수를 한눈에
- 하단 버튼: **이전 / 인쇄·PDF / JSON 내려받기 / 결과 저장**

> 참고 소견은 진단이 아니라 의료진이 확인할 항목을 표시한 것입니다. 확진과 중증도 판정은 수면다원검사(PSG)로 이루어집니다.

## 결과 저장

`결과 저장`을 누르면 서버에 저장합니다. 서버에 연결할 수 없으면 **태블릿 브라우저에 보관**했다가
`저장된 기록` 화면에서 함께 확인·내려받을 수 있습니다.

| 저장 위치 | 내용 |
|---|---|
| `data/responses.jsonl` | 서버 저장 — 한 줄에 결과 1건(JSON Lines) |
| 브라우저 localStorage | 서버 미연결 시 임시 보관 |

`저장된 기록`(`records.html`) 화면에서 목록 확인, 행을 누르면 전체 응답 펼쳐 보기,
**CSV / JSON 내려받기**(엑셀에서 한글이 깨지지 않도록 BOM 포함)가 가능합니다.

## 실행 방법

```bash
node server.js              # 기본 8080 포트
PORT=3000 node server.js    # 포트 변경
```

- 진료실 PC에서 실행 → 태블릿 브라우저에서 `http://<PC의 IP 주소>:8080` 접속
- 외부 라이브러리·빌드 도구가 전혀 없어 `node server.js` 하나로 바로 뜹니다 (Node 18 이상).
- 서버 없이 `index.html`을 태블릿에서 바로 열어도 설문 작성·결과 확인·저장(브라우저 보관)이 됩니다.

### API

| 메서드 | 경로 | 설명 |
|---|---|---|
| `POST` | `/api/responses` | 결과 1건 저장 (환자번호 필수) |
| `GET` | `/api/responses` | 저장된 결과 목록 |
| `GET` | `/api/responses.csv` | 전체 결과 CSV 내려받기 |

## 파일 구성

```
index.html           설문 화면
records.html         저장된 기록 화면
assets/schema.js     PART A 문항 정의 (문항 추가·수정은 이 파일에서)
assets/app.js        진행·검증·결과·저장 로직
assets/records.js    기록 목록 · CSV/JSON 내려받기
assets/styles.css    태블릿용 스타일 (인쇄 스타일 포함)
server.js            정적 파일 + 저장 API (의존성 없음)
data/                저장된 응답 (git 추적 제외)
```

문항을 바꾸려면 `assets/schema.js`의 `SECTIONS` 배열만 수정하면 됩니다.
설문 화면·결과 화면·CSV 열 순서가 모두 이 정의를 따라갑니다.

## 개인정보 안내

환자번호 외의 식별 정보는 수집하지 않지만, 저장된 응답은 진료 기록에 준하여 관리해야 합니다.
`data/` 폴더는 git 추적에서 제외되어 있으며, 병원 내부망에서만 운영하시기를 권장합니다.
