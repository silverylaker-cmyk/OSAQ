# 수면무호흡 원인 평가 설문지 (PART A)

수면무호흡증이 의심되는 환자가 **태블릿에서 직접 작성**하는 웹 설문 프로그램입니다.
원본 문진표의 **PART A(환자 작성)** 만 구현했으며, PART B(진찰 기록)와 PART C(원인 카테고리 해석)는
의료진 작성 영역이므로 포함하지 않았습니다.

## 화면 흐름

```
환자번호 입력 → A1 체중·신체 → A2 코골이·무호흡 양상 → A3 코 증상
            → A4 생활 요인 → A5 동반질환·기타 → A6 주간 졸림(Epworth) → 결과 한 화면
```

- **환자번호만 먼저 입력** — 이름·나이·성별은 받지 않습니다.
- 한 화면에 한 섹션씩, 큰 터치 버튼(최소 60px)으로 구성했습니다.
- 상단 진행 바 + 단계 칩으로 남은 분량을 보여 줍니다.
- 조건부 문항: 수면제 '예' → 약물명 / 고혈압 선택 → 혈압약 개수 / 폐경 후 → 악화 여부.
- 필수 문항을 비우고 다음으로 넘어가려 하면 해당 문항이 붉게 표시되고 그 위치로 이동합니다.
- 작성 중 내용은 브라우저에 자동 임시 저장되어, 태블릿이 잠기거나 새로고침돼도 이어서 작성할 수 있습니다.

## 결과 화면

마지막 단계에서 **전체 입력 내용을 한 화면**에 보여 줍니다.

- 상단 요약 카드 4개: BMI(자동 계산·분류), Epworth 합계 /24, 목격된 무호흡, 목 치수(cm 환산)
- 참고 소견 뱃지: 체중 증가, 목둘레 40cm 이상, 자세 의존성, 비강 요인, 취침 전 음주,
  수면제 복용, 흡연, 혈압약 3제 이상, 가족력, 폐경 후 악화, Epworth 10점 이상 등
- A1~A5 전체 응답을 2열 그리드로, A6는 8문항 점수를 한눈에
- 하단 버튼: **이전 / 인쇄·PDF / JSON 내려받기 / 결과 저장**

> 참고 소견은 진단이 아니라 의료진이 확인할 항목을 표시한 것입니다. 확진과 중증도 판정은 수면다원검사(PSG)로 이루어집니다.

## 결과 저장 — 두 가지 방식

`결과 저장`을 누르면 아래 중 **설정된 곳**에 저장됩니다. 어느 쪽이든 연결이 안 되면 태블릿에 대기열로 보관했다가,
연결이 복구되면 자동으로 전송합니다(같은 결과가 두 번 쌓이지 않도록 고유번호로 중복을 막습니다).

| 방식 | 서버 PC 필요 | 특징 |
|---|---|---|
| **구글 시트** (권장) | 필요 없음 | 구글이 24시간 받아 줍니다. 시트에서 엑셀(.xlsx)로 내려받기·공유·필터가 자유롭습니다. |
| **병원 서버** (`server.js`) | 켜 두어야 함 | 데이터가 병원 밖으로 나가지 않습니다. `data/responses.jsonl`에 쌓입니다. |

저장 위치는 설문 화면 우측 상단 **설정**(`settings.html`)에서 언제든 바꿀 수 있습니다.

### 구글 시트에 저장하기

> 구글 드라이브에 `.xlsx` 파일을 직접 쌓는 방식은 파일을 통째로 내려받아 다시 올려야 해서 동시 저장에 취약합니다.
> **구글 시트에 한 줄씩 추가**하고 필요할 때 엑셀로 내려받는 편이 안전하고 빠릅니다(`파일 › 다운로드 › Microsoft Excel(.xlsx)`).

1. 구글 드라이브에서 **새 스프레드시트**를 만듭니다. (병원·기관 구글 계정 권장)
2. 시트 상단 **확장 프로그램 › Apps Script**를 엽니다.
3. 편집기의 기존 코드를 지우고, 이 저장소의 **`google-apps-script/Code.gs`** 내용을 전부 붙여넣습니다.
4. 맨 위의 `var TOKEN = 'osaq-2026-changeme';` 를 병원에서 쓸 **암호로 바꾸고 저장**합니다.
5. 오른쪽 위 **배포 › 새 배포 › 유형: 웹 앱**을 선택하고
   - 실행 사용자: **나**
   - 액세스 권한: **모든 사용자** ← 이 값이 아니면 태블릿에서 저장되지 않습니다
   배포를 누르고 **권한 승인**을 마칩니다.
6. 표시된 `https://script.google.com/macros/s/…/exec` 주소를 복사합니다.
7. 태블릿에서 설문 프로그램을 열고 **설정** 화면에 주소와 4번의 암호를 넣은 뒤, **연결 테스트**로 확인합니다.

이후 태블릿에서 `결과 저장`을 누르면 시트에 한 줄씩 쌓입니다. 열 순서는 설문 문항 순서와 같고,
맨 끝 `원본데이터(JSON)` 열 덕분에 `저장된 기록` 화면에서 전체 응답을 다시 펼쳐 볼 수 있습니다.

> 코드를 고친 뒤에는 **배포 › 배포 관리 › 수정 › 버전: 새 버전**으로 다시 배포해야 반영됩니다.

### 병원 서버에 저장하기

설정 화면에서 구글 시트 주소를 비워 두면 같은 네트워크의 `server.js`에 저장합니다.

```bash
node server.js              # 기본 8080 포트
PORT=3000 node server.js    # 포트 변경
```

- 진료실 PC에서 실행 → 태블릿 브라우저에서 `http://<PC의 IP 주소>:8080` 접속
- 외부 라이브러리·빌드 도구가 없어 `node server.js` 하나로 바로 뜹니다 (Node 18 이상).
- 저장 위치: `data/responses.jsonl` (한 줄에 결과 1건)

| 메서드 | 경로 | 설명 |
|---|---|---|
| `POST` | `/api/responses` | 결과 1건 저장 (환자번호 필수) |
| `GET` | `/api/responses` | 저장된 결과 목록 |
| `GET` | `/api/responses.csv` | 전체 결과 CSV 내려받기 |

### 서버 없이 태블릿만으로 쓰기

구글 시트를 설정해 두면 `index.html`을 태블릿에서 바로 열어(파일로 복사하거나 홈 화면에 추가) 사용해도 됩니다.
설문 작성 → 결과 확인 → 구글 시트 저장까지 서버 PC 없이 그대로 동작합니다.

### 저장된 기록 화면

`저장된 기록`(`records.html`)에서 목록 확인, 행을 누르면 전체 응답 펼쳐 보기,
**CSV / JSON 내려받기**(엑셀에서 한글이 깨지지 않도록 BOM 포함), 전송 대기분 수동 전송이 가능합니다.

## 파일 구성

```
index.html                    설문 화면
records.html                  저장된 기록 화면
settings.html                 저장 위치 설정 (구글 시트 / 병원 서버)
assets/schema.js              PART A 문항 정의 (문항 추가·수정은 이 파일에서)
assets/app.js                 진행·검증·결과 화면 로직
assets/storage.js             저장소 계층 — 구글 시트 · 서버 · 오프라인 대기열
assets/records.js             기록 목록 · CSV/JSON 내려받기
assets/settings.js            설정 화면 로직
assets/styles.css             태블릿용 스타일 (인쇄 스타일 포함)
server.js                     정적 파일 + 저장 API (의존성 없음)
google-apps-script/Code.gs    구글 시트 저장용 Apps Script
data/                         서버 저장 응답 (git 추적 제외)
```

문항을 바꾸려면 `assets/schema.js`의 `SECTIONS` 배열만 수정하면 됩니다.
설문 화면·결과 화면·CSV 열 순서가 모두 이 정의를 따라갑니다.

## 개인정보 안내

환자번호 외의 식별 정보(이름·생년월일·연락처)는 수집하지 않지만, 저장된 응답은 **진료 정보에 준하여** 관리해야 합니다.

- 구글 시트를 쓸 경우: **병원(기관) 구글 계정**을 사용하고, 시트 공유 범위를 담당자만으로 제한하세요.
  "링크가 있는 모든 사용자" 공유는 피해 주세요. Apps Script의 `TOKEN`은 기본값을 반드시 바꾸세요.
- 병원 서버를 쓸 경우: `data/` 폴더는 git 추적에서 제외되어 있으며, 병원 내부망 운영을 권장합니다.
- 환자번호는 병원 내부에서 개인을 특정할 수 있는 정보이므로, 클라우드 저장 여부는 병원의 개인정보 처리 방침에 맞춰 결정하세요.
